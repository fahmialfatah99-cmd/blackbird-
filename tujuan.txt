Bertindaklah sebagai Principal Full-Stack Engineer dan Product Architect. Saya ingin membangun aplikasi messenger multi-perangkat bernama "BluePin Messenger" dengan fungsi inti seperti BlackBerry Messenger, tetapi lebih modern, aman, dan scalable.

TUJUAN UTAMA:
Buat aplikasi chat lintas perangkat yang mendukung Android, iOS, Web, dan opsional Desktop. Aplikasi harus memiliki sistem akun, kontak, chat personal, chat grup, status pesan, presence/online, profil, notifikasi, dan UI dark blue-black modern.

ATURAN WAJIB:
1. Jangan membuat fitur dummy, data palsu, mock API, atau state statis yang berpura-pura berfungsi.
2. Semua fitur utama harus benar-benar terhubung ke database, authentication, realtime, dan storage.
3. Gunakan validasi form, error handling, loading state, empty state, dan success notification.
4. Semua data harus tersimpan permanen dan dapat digunakan kembali setelah refresh/reload atau restart aplikasi.
5. Gunakan struktur proyek yang bersih, modular, scalable, dan production-ready.
6. Pastikan autentikasi aman, password di-hash, dan akses data dilindungi permission/RLS.
7. Jangan hanya membuat tampilan. Bangun logika asli yang berfungsi.
8. Jika ada fitur yang belum bisa diselesaikan sekaligus, pecah menjadi tugas implementasi bertahap dengan prioritas jelas.

STACK YANG DIGUNAKAN:
- Frontend Mobile: React Native + Expo
- Frontend Web: Next.js atau React PWA
- Backend: Supabase
  - Supabase Auth
  - Supabase PostgreSQL
  - Supabase Realtime
  - Supabase Storage
  - Supabase Edge Functions bila diperlukan
- State Management: Zustand atau React Query
- Styling: Tailwind CSS untuk web, NativeWind atau sistem desain internal untuk mobile
- Push Notification: Firebase Cloud Messaging untuk Android dan APNs untuk iOS bila memungkinkan
- Shared package untuk component, types, API client, hooks, dan utility

DATABASE SCHEMA MINIMAL:
Buat tabel berikut dengan relasi, index, dan Row Level Security:

1. profiles
   - id uuid primary key
   - bluepin_id text unique
   - username text unique
   - display_name text
   - avatar_url text
   - personal_status text
   - bio text
   - show_last_seen boolean
   - show_read_receipt boolean
   - allow_messages_from_non_contacts boolean
   - last_seen_at timestamptz
   - created_at timestamptz
   - updated_at timestamptz

2. contacts
   - id uuid primary key
   - owner_id uuid references profiles
   - contact_id uuid references profiles
   - status text: pending, accepted, blocked
   - created_at timestamptz
   - updated_at timestamptz

3. conversations
   - id uuid primary key
   - type text: direct, group
   - name text nullable
   - avatar_url text nullable
   - created_by uuid
   - created_at timestamptz
   - updated_at timestamptz

4. conversation_members
   - id uuid primary key
   - conversation_id uuid references conversations
   - user_id uuid references profiles
   - role text: admin, member
   - joined_at timestamptz
   - muted boolean
   - archived boolean
   - last_read_message_id uuid nullable

5. messages
   - id uuid primary key
   - conversation_id uuid references conversations
   - sender_id uuid references profiles
   - type text: text, image, system
   - content text
   - attachment_url text nullable
   - reply_to_message_id uuid nullable
   - edited_at timestamptz nullable
   - deleted_at timestamptz nullable
   - created_at timestamptz

6. message_receipts
   - id uuid primary key
   - message_id uuid references messages
   - user_id uuid references profiles
   - status text: delivered, read
   - updated_at timestamptz

7. typing_indicators
   - conversation_id uuid
   - user_id uuid
   - is_typing boolean
   - updated_at timestamptz

8. presence
   - user_id uuid primary key
   - is_online boolean
   - last_seen_at timestamptz

9. notifications
   - id uuid primary key
   - user_id uuid
   - type text
   - payload jsonb
   - read boolean
   - created_at timestamptz
